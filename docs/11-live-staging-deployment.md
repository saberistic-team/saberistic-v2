## Deployment behavior

- Render builds the checked-in multi-stage `Dockerfile` and runs the application as the non-root `nextjs` user.
- `DATABASE_URL` is injected from the Blueprint-managed database.
- `PAYLOAD_SECRET` is generated by Render and is not stored in Git.
- The committed Payload migration runs before every container start. The first start applied `20260828_221439_initial_platform`; the final replacement start found no pending migration and completed cleanly.
- `/api/ready` is the Render health check.
- Automatic deployments wait for GitHub checks to pass.
- The first Blueprint sync and the checks-passed auto-deploy briefly produced two deploys of the same commit. The cached second deploy became the final active version and the first was deactivated normally.
